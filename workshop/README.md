# Workshop

Bienvenue dans le Workshop de Projet Atlas.

Le Workshop est l'atelier du projet.

C'est ici que naissent les idees.

Certaines deviendront des fonctionnalites.
D'autres resteront de simples experimentations.
D'autres encore seront abandonnees.

Et c'est parfaitement normal.

Le Workshop n'est pas une documentation.
Ce n'est pas une roadmap.
Ce n'est pas un cahier des charges.

C'est un espace de reflexion.

Une idee presente ici n'est jamais consideree
comme officielle.

Une idee devient officielle uniquement lorsqu'elle
est integree au DevBook,
validee par un ADR
ou integree a la documentation officielle.

Le Workshop est volontairement libre.
Le DevBook est volontairement rigoureux.

Les deux sont complementaires.

Bienvenue dans l'atelier.
