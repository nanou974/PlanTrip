# Préparer un voyage ne devrait pas demander dix applications.

Aujourd'hui, organiser des vacances signifie souvent jongler entre une multitude de services :

- 🗺️ Cartes
- ✈️ Réservations
- 🏨 Hébergements
- 💰 Budget
- 📄 Documents
- 📸 Souvenirs
- 📝 Notes
- 📅 Planning

PlanTrip rassemble tout cela dans un espace unique, pensé dès le départ pour rester simple, durable et respectueux de ses utilisateurs.

---

# Pourquoi PlanTrip ?

Nous pensons que préparer des vacances devrait être un plaisir.

Pas une succession de fichiers Excel, de captures d'écran, d'e-mails et d'applications dispersées.

PlanTrip est conçu pour devenir le compagnon de voyage qui centralise toutes les informations importantes avant, pendant et après vos vacances.

---

# Les grands principes

✅ Vos données vous appartiennent.

✅ Fonctionne même sans connexion Internet.

✅ Pas de publicité.

✅ Pas de fonctionnalités verrouillées artificiellement.

✅ Pensé pour durer.

# Architecture

PlanTrip repose sur une architecture modulaire pensée pour évoluer pendant de nombreuses années.

Les principaux principes sont :

- Architecture en couches
- Offline First
- Domaine indépendant des technologies
- Synchronisation asynchrone
- Modèle orienté événements
- Modularité maximale

Tous les détails sont disponibles dans le DevBook.
