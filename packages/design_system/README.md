# design_system

`design_system` regroupe les tokens visuels et composants réutilisables
de PlanTrip (couleurs, typographie).

## A le droit de connaître

- Flutter uniquement.

## N'a pas le droit de connaître

- `domain`, `application`, `infrastructure`, `presentation`.

L'identité visuelle de PlanTrip ne doit jamais dépendre d'une
fonctionnalité métier particulière.
